SMS Send

POST https://api.textzy.in/api/public/messages/send

Send a DLT-compliant SMS using tenant credentials (SMS-style auth).

Request Header Parameters

NameDescriptionMandatory
Content-Typeapplication/jsonY

Request Body Parameters

KeyTypeDescriptionMandatory
tenantSlugstringTenant slugY
userstringPublic API userY
pswdstringPublic API passwordY
apikeystringPublic API keyY
recipientstringMobile number with country codeY
messagestringApproved DLT messageY
senderstringDLT sender IDY
peIdstringDLT PE IDY
templateIdstringDLT Template IDY
idempotencyKeystringOptional de-dup keyN

Example (POST)

cURL RequestSMS
curl --request POST \
--url https://api.textzy.in/api/public/messages/send \
--header 'accept: application/json' \
--header 'content-type: application/json' \
--data '{
"tenantSlug":"moneyart",
"user":"MONEYART",
"password":"YOUR_PASSWORD",
"apiKey":"YOUR_API_KEY",
"channel":"sms",
"recipient":"919999999999",
"message":"Your approved DLT message",
"sender":"MNYART",
"peId":"1601100000000006533",
"templateId":"1207171593687982329"
}'

Response

200 - Result
{"jobId":"GUID","message":"Accepted"}

DigiLocker KYC

Create a KYC session and redirect the user to DigiLocker for consent.

Query Parameters

KeyTypeDescriptionMandatory
tenantSlugstringTenant slugY
userstringPublic API userY
pswdstringPublic API passwordY
apikeystringPublic API keyY
providerstringMust be `digilocker`Y
docTypestring`AADHAAR`, `PAN`, `DL`Y
customerRefstringYour referenceN
successRedirectUrlstringRedirect after successN
failureRedirectUrlstringRedirect after failureN
webhookUrlstringWebhook for resultN

Example (GET)

cURL RequestDigiLocker

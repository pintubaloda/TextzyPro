WhatsApp API Reference

Endpoint-first documentation for public plain-text sends, tenant-authenticated messaging, templates, media, interactive flows, webhooks, and automation operations.

Base URL: https://api.textzy.in Public auth: tenantSlug + user + password + apiKey Tenant app auth: cookie session + CSRF
ChannelWhatsApp
Public ModePlain Text
Authenticated ModeTemplates, Media, Flows
RealtimeInbox + Automation

Public WhatsApp Send

Use the public endpoint when an external system needs to send a plain WhatsApp text message through Textzy with tenant-scoped API credentials.

GET/api/public/messages/send
POST/api/public/messages/send

GET Request

https://api.textzy.in/api/public/messages/send?recipient=919999999999&msg=Hello from Textzy WhatsApp API&user=MONEYART&pswd=YOUR_PASSWORD&apikey=YOUR_API_KEY&channel=whatsapp&tenantSlug=moneyart

POST Request

{
  "recipient": "919999999999",
  "message": "Hello from Textzy WhatsApp API",
  "user": "MONEYART",
  "password": "YOUR_PASSWORD",
  "apiKey": "YOUR_API_KEY",
  "tenantSlug": "moneyart",
  "channel": "whatsapp",
  "idempotencyKey": "wa-20260311-0001"
}
The public WhatsApp API is for simple plain-text sends. Richer capabilities like templates, media, interactive buttons, and flows are available through authenticated tenant APIs.

Authenticated Tenant Messaging

Use authenticated tenant APIs when messages originate from Textzy web, mobile, desktop, inbox, or workflow execution.

POST/api/messages/send

Session Message

{
  "recipient": "919999999999",
  "channel": "WhatsApp",
  "body": "Hello from Textzy",
  "useTemplate": false
}

Template Message

{
  "recipient": "919999999999",
  "channel": "WhatsApp",
  "useTemplate": true,
  "templateName": "order_update",
  "templateLanguageCode": "en",
  "templateParameters": ["John", "#1234"]
}

Interactive Buttons

{
  "recipient": "919999999999",
  "channel": "WhatsApp",
  "isInteractive": true,
  "interactiveType": "button",
  "body": "How can we help you?",
  "interactiveButtons": ["Support", "Sales", "Accounts"]
}

Interactive Flow

{
  "recipient": "919999999999",
  "channel": "WhatsApp",
  "isInteractive": true,
  "interactiveType": "flow",
  "body": "Open the flow below.",
  "interactiveFlowId": "FLOW_ID",
  "interactiveFlowCta": "Open",
  "interactiveFlowAction": "navigate",
  "interactiveFlowScreen": "start",
  "interactiveFlowDataJson": "{}",
  "interactiveFlowMessageVersion": 3
}
Session messaging is subject to WhatsApp conversation-window rules. Use approved templates when a session message is not allowed.

Request Fields

FieldUsed InDescription
recipientPublic and authenticatedWhatsApp number with country code.
message / msgPublicPlain text message body.
bodyAuthenticatedSession or interactive message body.
tenantSlugPublicTenant slug that owns the credentials.
user / password / apiKeyPublicTenant-scoped public API credentials.
templateNameAuthenticatedApproved WhatsApp template name.
templateLanguageCodeAuthenticatedTemplate language code, for example en.
interactiveTypeAuthenticatedbutton, list, or flow.

Webhook Endpoint

GET/api/waba/webhook
POST/api/waba/webhook
Meta inbound delivery, status, and interaction callbacks are received through the WABA webhook endpoint.

Implementation Checklist

  • Generate tenant public API credentials in Integrations.
  • Configure WABA and template approvals.
  • Use public API for simple text sends only.
  • Use authenticated APIs for templates, media, inbox, and flows.
  • Monitor webhook status and inbox delivery flow in platform analytics.
